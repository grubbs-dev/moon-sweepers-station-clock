# Station Clock

Know when the sun is coming up or going down in Moon Sweepers.

A compact top-left HUD shows:
Local time: 06:14 | Sunset in 00:29:25

At night, the countdown switches to Sunrise. The display updates twice per second and uses your current position. No DAY/NIGHT badge or keybind is needed.

Local time represents a lunar day on a 24-hour dial. The countdown is real time remaining at the current game speed.

COMPATIBILITY
Windows x64, tested on Moon Sweepers 1.0.5. Tested alongside Sleep Until Dawn, with the HUD updating after Sleep and Nap. Sleep Until Dawn is optional. Multiplayer and station travel have not been verified for Station Clock.

REQUIREMENTS
BepInEx 6.0.0-be.791 Unity IL2CPP win-x64: https://builds.bepinex.dev/projects/bepinex_be/791
MoonSweepers BepInEx Patcher by boverson777: https://www.nexusmods.com/moonsweepers/mods/9

INSTALL
Close the game. Install both requirements following their instructions. Extract this mod ZIP into the folder containing MoonSweepers.exe.
Final path: BepInEx/plugins/StationClock/StationClock.dll
Remove older duplicate StationClock.dll files before installing. Manual installation is documented; Vortex deployment has not been tested.

UNINSTALL
Close the game and remove BepInEx/plugins/StationClock.
