Station Clock 0.1.1 for Moon Sweepers 1.0.5 (Windows x64).

Top-left HUD with local solar time and a real-time sunrise/sunset countdown. Updates after Sleep Until Dawn time skips. Sleep Until Dawn is optional; multiplayer and station travel have not been verified for this HUD.

Requires BepInEx 6.0.0-be.791 Unity IL2CPP win-x64 and MoonSweepers BepInEx Patcher by boverson777. Dependencies are linked in README and are not bundled.

Extract the ZIP into the game directory containing MoonSweepers.exe. Final path: BepInEx/plugins/StationClock/StationClock.dll. Remove older duplicate copies first.
